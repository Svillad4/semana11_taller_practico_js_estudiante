# Rubrica de evaluacion - Semana 11 Taller practico

| Criterio | Nivel alto | Nivel medio | Nivel bajo | Valor |
|---|---|---|---|---:|
| Identificacion de errores frecuentes | Identifica y explica varios errores de referencia, tipo, logica, eventos y control de flujo | Identifica algunos errores, pero con explicaciones parciales | No identifica los errores principales o los confunde | 20% |
| Correccion tecnica del codigo | Corrige el sistema sin romper funciones y mantiene codigo claro | Corrige parcialmente, pero deja fallos menores | El sistema no funciona o se corrige sin criterio | 25% |
| Depuracion sistematica | Usa consola, pruebas, lectura de errores y bitacora de manera ordenada | Usa algunas herramientas de depuracion, pero sin mucha documentacion | Corrige por ensayo y error sin evidencias | 20% |
| Pruebas y evidencias | Presenta matriz de pruebas completa, capturas y consola con PASS | Presenta evidencias incompletas o poco claras | No presenta evidencias suficientes | 20% |
| Organizacion del repositorio y documentacion | Entrega carpeta ordenada, archivos completos y bitacora clara | Entrega con pequenos desordenes o documentos incompletos | Entrega desorganizada o sin documentos requeridos | 15% |
| Total | | | | 100% |

## Criterios de no aprobacion automatica segun indicacion docente

El docente puede considerar no aprobado el taller si:

- No se entrega el proyecto en ZIP.
- No se incluye `js/app.js` corregido.
- No hay evidencias de ejecucion.
- La entrega no corresponde al proyecto asignado.
- El trabajo no abre en navegador.
