# Enunciado para Moodle - Semana 11 Taller practico

## Titulo de la tarea

Semana 11 - Taller practico: errores frecuentes en JavaScript, depuracion sistematica y control de flujos

## Descripcion

En esta actividad deberas abrir en Visual Studio Code un proyecto web con errores intencionales en JavaScript. Tu reto consiste en ejecutar el sistema, revisar la consola del navegador, identificar errores, corregir el archivo `js/app.js`, probar el funcionamiento y entregar evidencias.

## Producto a entregar

Sube un archivo ZIP con:

1. Carpeta completa del proyecto corregido.
2. Archivo `js/app.js` ajustado.
3. Matriz de pruebas diligenciada.
4. Bitacora de depuracion diligenciada.
5. Capturas de consola y pruebas.
6. Captura del sistema funcionando.

## Modalidad

Individual o en parejas, segun indicacion del docente.

## Herramientas

- Visual Studio Code.
- Navegador web.
- Consola del navegador.
- Moodle para entrega.

## Criterios principales

- Identificacion de errores frecuentes en JavaScript.
- Correccion tecnica.
- Uso de depuracion sistematica.
- Evidencia de pruebas.
- Organizacion de la carpeta del proyecto.
