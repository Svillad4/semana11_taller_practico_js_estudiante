# Evidencias de capturas y consola

Debes incluir capturas claras. Puedes guardarlas en la carpeta `evidencias/`.

## Capturas minimas obligatorias

1. Captura de VS Code con la carpeta del proyecto abierta.
2. Captura de la consola mostrando al menos un error antes de corregir.
3. Captura del codigo corregido en `js/app.js`.
4. Captura de `index.html` funcionando con registros en la tabla.
5. Captura de `tests.html` con pruebas aprobadas.
6. Captura de la consola con pruebas PASS.

## Recomendaciones

- Las capturas deben ser legibles.
- No recortes la parte importante del error.
- Si el error menciona una linea, intenta que se vea el archivo o la funcion relacionada.
- Nombra los archivos de forma ordenada.

Ejemplo:

```txt
captura_01_vscode.png
captura_02_error_consola.png
captura_03_codigo_corregido.png
captura_04_sistema_funcionando.png
captura_05_tests_aprobados.png
```
