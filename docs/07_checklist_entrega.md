# Checklist de entrega

Antes de subir el ZIP a Moodle, verifica:

- [ ] La carpeta abre correctamente en Visual Studio Code.
- [ ] `index.html` carga en el navegador.
- [ ] El formulario registra datos validos.
- [ ] Los datos invalidos muestran mensajes de error.
- [ ] La tabla muestra registros sin errores.
- [ ] El resumen calcula total y promedio.
- [ ] El boton de datos de ejemplo funciona al hacer clic.
- [ ] El boton limpiar funciona.
- [ ] `tests.html` muestra pruebas aprobadas.
- [ ] La consola no muestra errores criticos.
- [ ] Complete la matriz de pruebas.
- [ ] Complete la bitacora de depuracion.
- [ ] Agregue capturas en la carpeta `evidencias`.
- [ ] El ZIP tiene el nombre indicado por el docente.
